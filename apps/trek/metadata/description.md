# TREK

TREK is a self-hosted travel planner that keeps every part of your trip in one place.

## Features

- Plan itineraries together in real time with interactive maps and routing.
- Keep bookings, budgets and shared expenses organized.
- Prepare packing lists and record your travels in a journal.
- Access your trips on your phone with an offline-capable progressive web app.

## Getting started

Sign in with the admin email and password you entered during installation. TREK will ask you to change the initial password. These installation settings only create the account on first startup; manage subsequent password changes inside TREK.

Enable **Secure cookies** in the app settings when accessing TREK exclusively over HTTPS. Leave it disabled if you use local HTTP access. Installing TREK as a progressive web app requires HTTPS.

Your database and uploads are stored persistently. Keep the generated encryption key with your backups, as it is used to encrypt stored secrets.

Try the [demo](https://demo.liketrek.com) or visit the [documentation](https://github.com/liketrek/TREK/wiki) for more information.
